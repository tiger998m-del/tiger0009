# tiger0009

مدونة باللغة الإنجليزية

قالب Blogger احترافي جاهز للنشر + صفحات AdSense الأساسية + قالب مقالات منظم بعناوين H2.
راجع **[GUIDE-AR.md](GUIDE-AR.md)** لخطوات التركيب الكاملة وقائمة تحقق قبول AdSense.

## محتويات المستودع
- `theme/tiger0009-theme.xml` — قالب Blogger كامل (نظيف، متجاوب، سريع، SEO، بدون إعلانات منبثقة)
- `pages/` — محتوى صفحات About / Contact / Privacy Policy / Disclaimer الجاهزة للصق في Blogger
- `post-template/post-template.html` — قالب كتابة مقال منظم (مقدمة/محتوى/أسئلة شائعة/خاتمة) بعناوين H2 + Schema FAQ
